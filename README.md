### 连接 AI：使用官方 API

目前已支持**主流文本模型的官方 API，以及火山方舟上的文本模型**。**第三方中转站暂不兼容，请使用官方 API。**

在“连接 AI”中填写服务地址、API 密钥和模型名称。服务地址应填写 API 地址，不能使用聊天网页的网址；密钥、地址和模型须对应同一服务。

**火山方舟用户：** 请复制控制台提供的完整 Model ID，或该调用方式要求的接入点 ID，不要只填写“豆包”等展示名称。

点击“测试并保存”会发送一次短字幕样例，可能产生少量费用。测试成功后，再开始 AI 推荐包装或分析字幕。

> **小 tips：先充一两块，够试就好。**
>
> 钱包先别急着冲！如果平台支持小额充值，先充 1-2 元试试水就好。SC 做的是字幕文本分析，不是让 AI 看完整段视频，通常用不了多少 token。用完再添，别让余额先替你“加班”。实际花费取决于模型单价、字幕长度和分析次数。

视频和音频留在本机；字幕及必要结构信息会发送到你连接的 AI 服务。“重新适配（本地）”会复用已有分析结果，不再调用模型；“重新分析（在线）”会再次调用并可能计费。

不需要自己安装 Node.js、Python，也不需要使用 AI 帮你配置环境。**完整安装包已经包含运行所需的组件。**

打开 **[Releases 下载页面](https://github.com/SupePotato/SmartCharacter/releases/latest)**，在 **Assets（附件）** 中选择：

| 你的电脑 | 对应安装包 |
|---|---|
| **Windows 11 · Intel / AMD x64** | [SC-Windows.zip](https://github.com/SupePotato/SmartCharacter/releases/latest/download/SC-Windows.zip) |
| **Intel 芯片 Mac · macOS 14 或更高** | [SC-Mac-Intel.zip](https://github.com/SupePotato/SmartCharacter/releases/latest/download/SC-Mac-Intel.zip) |
| **Apple 芯片 Mac（M 系列）· macOS 14 或更高** | [SC-Mac-AppleSilicon.zip](https://github.com/SupePotato/SmartCharacter/releases/latest/download/SC-Mac-AppleSilicon.zip) |

Windows ARM（如骁龙）、32 位系统和 Windows 10 不在当前交付范围。

```text
下载对应的 ZIP
    → 完整解压
    → 点击“安装 SmartCharacter”
    → 安装完成后点击“启动 SmartCharacter”
    → 浏览器打开 SC，开始使用
```

1. **完整解压。** 将 ZIP 解压到普通文件夹，尤其是 Windows，不要直接在压缩包里运行。
2. **首次安装。** 按下表双击对应的安装文件。
3. **启动 SC。** 安装完成后，双击同文件夹中的启动文件。
4. **开始使用。** 浏览器会自动打开 SC 工作台。

## 完整制作流程

### 准备两个文件

| 文件 | 要求 |
|---|---|
| **粗剪视频** | 当前版本面向 **9:16 竖屏视频** |
| **SRT 字幕** | 与粗剪视频内容、时间对应 |

![SC 导入首页：选择视频、SRT 和包装方式](assets/sc-import-screen-v1.png)

### 从导入到剪辑完成

```text
你的粗剪视频 + 对应 SRT 字幕
    → SC 导入视频和字幕
    → 选择基础包装，或 AI 推荐包装
    → 编辑台预览、调整重点词效果
    → 按需要制作段落卡片
    → 导出透明 MOV 字幕层
    → 放回剪辑软件，叠加在原视频上
    → 完成最终剪辑
```

1. **导入素材：** 在 SC 首页选择粗剪视频和对应的 SRT 字幕。
2. **生成包装：** 选择“基础包装”，或连接 AI 后选择“AI 推荐包装”，点击开始。
3. **调整效果：** 检查字幕、重点词和包装样式，按需要换效果、改颜色、调整位置、大小和时间。
4. **制作卡片：** 选取合适的字幕，选择卡片，修改内容后应用。
5. **导出字幕层：** 点击“导出字幕层”，等待透明 MOV 生成。
6. **完成剪辑：** 将 MOV 放进剪辑软件，叠加到原视频上，预览并完成最终剪辑。

> **SC 导出的是字幕与包装层。**
>
> 原视频继续留在你的剪辑工程中。将透明字幕层叠加到原视频上，即可呈现完整效果。

## 常见问题

### 使用与费用

| 问题 | 说明 |
|---|---|
| **SC 是免费的吗？** | SC 基础版免费使用，内置效果和基础包装无需付费。可选的 AI 功能可能产生 API 费用，按你连接的服务商规则计算。 |
| **必须连接 AI 吗？** | 不用。基础包装可以在本机完成，也可以手动选词、制作卡片和微调效果。 |
| **为什么打开的是浏览器？** | SC 在本机运行，通过浏览器提供操作界面。启动程序会启动本地服务，并打开工作台。 |
| **视频会上传吗？** | 视频在本机处理。使用 AI 推荐包装时，字幕文本会发送给你连接的 AI 服务进行分析。 |
| **启动窗口可以关闭吗？** | 使用期间请保持窗口运行。关闭启动窗口会停止本地服务，网页里的处理功能也会停止。 |

### 导出的 MOV 无法直接播放？

SC 导出的是 **带透明通道的 ProRes 4444 字幕层**，主要供剪辑软件使用。部分普通播放器不支持这种格式。

请将文件放进支持该格式的剪辑软件查看，并叠加到原视频上。

### 导出文件在哪里？

**Mac：**

```text
~/Library/Application Support/SmartCharacterLocalWeb/exports
```

**Windows：**

```text
%LOCALAPPDATA%\SmartCharacterLocalWeb\exports
```

浏览器下载的副本保存在浏览器设置的下载位置。详细查找方式见 [本地启动说明](本地启动说明.md)。
